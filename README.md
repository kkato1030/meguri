# meguri

> **meguri is a local-first delivery control plane that turns intent into an
> executable work graph and coordinates humans and AI agents toward the
> desired state.**

Intent を実行可能な Work Graph に変換し、人間と AI Agent による実行・判断を
通じて Desired State への到達を管理する、local-first な Delivery Control Plane。

開発計画は `docs/plan.md` を参照。
